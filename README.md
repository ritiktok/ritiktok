## What I’m building

### Pokate Labs — my main project

**Infrastructure for agents using real computers.**

I’m building Pokate Labs to help people delegate computer work to AI agents while staying informed and in control. The product direction brings together scoped execution, human oversight, task continuity, supported recovery, and clear evidence of what happened.

- **Control:** give agents bounded capabilities and keep execution policy on the host.
- **State:** carry useful task context across agents without transferring credentials or authority.
- **Safety:** make supported changes reviewable and recoverable while preserving human work.
- **Lab:** evaluate systems with repeatable scenarios and honest evidence.

Pokate Labs is an evolving portfolio; product maturity varies. The organization docs label experimental, preview, and planned work clearly.
